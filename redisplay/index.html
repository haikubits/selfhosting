A full Redis engine (strings, hashes, lists, sets, sorted sets, expiry, transactions) runs entirely in your browser via JavaScript. Lua EVAL/EVALSHA run through an embedded Lua 5.3 VM (Fengari). No server, no signup, data persists to this browser's local storage.

                
This is the default and recommended mode for learning.

            


            

                
Connect to a real Upstash Redis database over its REST API (works from the browser, free tier available).

                

                    
                    
                

                

                    
                    
                

            


            

                
Run the official Redis image locally, fronted by webdis (an HTTP↔Redis bridge, since browsers cannot open raw TCP sockets). Bound to 127.0.0.1 only for safety.

                

                    
1. docker-compose.yml

                    
services:
  redis:
    image: redis:7-alpine
    ports:
      - "127.0.0.1:6379:6379"
  webdis:
    image: nicolas/webdis
    volumes:
      - ./webdis.json:/etc/webdis.json
    ports:
      - "127.0.0.1:7379:7379"
    depends_on:
      - redis

                

                

                    
2. webdis.json (enables CORS)

                    
{
  "redis_host": "redis",
  "redis_port": 6379,
  "http_host": "0.0.0.0",
  "http_port": 7379,
  "threads": 2,
  "http_headers": {
    "Access-Control-Allow-Origin": "*",
    "Access-Control-Allow-Methods": "GET, POST, OPTIONS"
  }
}

                

                

                    
3. Run it

                    
docker compose up -d
# or without compose:
docker run -d --name redisplay-redis -p 127.0.0.1:6379:6379 redis:7-alpine
docker run -d --name redisplay-webdis -p 127.0.0.1:7379:7379 \
  -v "$PWD/webdis.json:/etc/webdis.json" nicolas/webdis

                

                

                    
                    
                

                
MULTI/EXEC transactions are not supported over HTTP bridges (each request is a separate connection); use Simulated mode to practice transactions. EVAL and all single commands work normally.

Generic
